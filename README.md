# 1 проект
Небольшой демо-проект на Three.js, который генерирует 3D-рельеф по высотной карте и накладывает тайловые текстуры травы и ландшафта в браузере.​

Структура проекта
index.html — контейнер для канвы и подключение Three.js и main.js.​

main.js — инициализация сцены, камеры, света; выборка высот из изображения и построение сетки; загрузка текстур.​

three.min.js — библиотека Three.js.​

images: plateau.jpg — высотная карта; grasstile.jpg, landtile.jpg, lake.jpg, yachik3.jpg — текстуры.​

.vscode/launch.json — конфигурация запуска Chrome на localhost:8080.

# 2 проект  
 Данный проект реализует визуализацию моделирования солнечной системы с помощью библиотеки Three.js. В составе проекта используются карты текстур для различных небесных тел (Солнце, Земля и др.), а визуализация отображается в окне браузера. Все вычисления и отображение происходят в 3D пространстве на базе WebGL.

Структура проекта
index.html — основной HTML-файл, загружает сцену, подгружает Three.js и основной скрипт.

script.js — основной сценарий. Содержит создание и анимацию планет, их движение по орбитам, настройку камеры и пользовательского управления. Используются текстуры для планет.

sunmap.jpg — карта текстуры Солнца, используется для моделирования его поверхности в 3D.

earthmap1k.jpg — карта текстуры Земли, используется для создания отображения планеты Земля.

launch.json — конфигурационный файл для запуска проекта в среде разработки (например, VS Code), настроен для запуска локального сервера.

Запуск проекта
Убедитесь, что у вас установлен современный браузер и что есть возможность запускать локальный сервер (например, через Live Server или Python SimpleHTTPServer).

Откройте папку проекта в вашей среде разработки.

Запустите локальный сервер и откройте index.html в браузере.

Наслаждайтесь визуализацией солнечной системы.
